# SV Sachverständiger – Webseite

Webseite für SV Sachverständiger (Kfz-Gutachten, Bewertung, Beratung) in Ingolstadt, Pfaffenhofen und Umgebung.

| Datei | Inhalt |
| --- | --- |
| `daten.txt` | Telefon, E-Mail, Adresse, Impressum – **hier Daten ändern** |
| `index.html` | die Webseite (Design, Texte, Logo, Schrift) |
| `kontakt.php` | verschickt Formular-Anfragen als E-Mail (läuft beim Webhoster) |
| `ANLEITUNG.txt` | Schritt-für-Schritt-Anleitung für Änderungen ohne Vorkenntnisse |

Online stellen: alle Dateien beim Webhoster im Hauptordner der Domain hochladen.
